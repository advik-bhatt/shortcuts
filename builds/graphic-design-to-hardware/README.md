# Build dossier — graphic design to hardware

Take a 2D graphic design (an SVG vector or a raster image) and turn it into physical motion on a machine you build yourself: software converts the design to G-code toolpaths, open firmware on a microcontroller runs the G-code, and a host app streams it over USB to a 2-axis machine (pen plotter, drag-knife cutter, or light diode laser) assembled from orderable parts.

This folder was generated by **anything-engine**. It decomposed the goal into
subsystems, searched real component sources for each, and assembled the result.
Nothing here is invented: every software pick links to a real repo/package, and
every part links to a real product with a real price.

## What is in this folder
- `bill-of-materials.md` / `order-list.csv` — the parts to order.
- `software-stack.md` — every repo/package to clone or install, per stage.
- `build-steps.md` — exactly what to do, in order.
- `plan.json` — the raw machine-readable plan.
